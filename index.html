pentest toolkit

OSCP / CTF

Four tools that fit together: run the enum, work out what to do with what it finds, look up any command, and keep the syntax off your shoulders. Everything runs offline in the browser or the shell, no data leaves the machine.

Box playbook
oscp-playbook.html
The command centre. Switchable tracks (recon, web, Linux, Windows, AD, pivoting, buffer overflow, passwords, AV evasion), a scan planner that reads pasted nmap output and lists per-service commands, a reverse-shell generator, a hash identifier, an exploit suggester, a proof checklist, a per-box credentials and notes tracker, per-step evidence capture with an auto write-up generator (markdown and print/PDF), a timer, and one-click report and .sh export. Set your IP once and every command fills in.
Arsenal reference
oscp-arsenal.html
1,028 commands from the Orange Cyberdefense arsenal, searchable and colour-coded by engagement phase. The playbook deep-links into this pre-filtered.
Cheat sheet
oscp-cheatsheet.md
The printable quick reference, grouped by port and by phase. Best viewed in your notes app or a markdown viewer.
Enum runner
oscp-enum.sh
First-pass enumeration script. Scans, then fires the right per-service tools, printing and logging every command so it doubles as syntax practice. ./oscp-enum.sh <ip>
Arsenal refresh
build-arsenal.sh
Re-clones the upstream repo and rebuilds the arsenal reference so it never goes stale. ./build-arsenal.sh

Authorised testing only. Some entries (sqlmap, automated exploitation, Metasploit beyond the permitted box) are off-limits on the OSCP exam; the tools flag these where relevant.
